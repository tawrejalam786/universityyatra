# Russia and Australia country pages: Canada design system migration

Both Russia and Australia country pages migrated from legacy design patterns to the Canada/Ireland design system. The migration replaced video-based heroes with image-based layouts, replaced Swiper.js carousels with custom 3D arc implementations, created guide page infrastructure matching Ireland's pattern, and updated all components to use consistent brand colors (#1765F5 primary, #0C337B navy, #18B8B5 teal). Build succeeds, all guide routes generate as static pages, and Russia/Australia-specific content (universities, programs, currencies, cities) preserved throughout.

**Watch for:** None. The migration is complete and consistent with the Canada/Ireland design system.

**Verdict**: APPROVED

## High-level view

Both countries received identical design system updates following the Ireland reference implementation. Hero components migrated from video backgrounds to static image overlays with centered headings, two CTAs (consultation + WhatsApp), gradient overlays, and Framer Motion animations. University carousels abandoned Swiper.js for the custom 3D arc implementation with touch/mouse drag, autoplay, and perspective transforms applied to 12 Russian universities and 8 Australian universities. 

The OnlineDegreeSection transformed from basic layout to Ireland's tab-based guide structure, linking to 5 guide pages per country. Guide pages follow Ireland's dynamic route pattern with markdown content, hero sections, pill badges, and article styling.

All 9 components per country (Hero, OnlineDegreeSection, UniversityCarousel, WhatItGetsYou, CoursesSlider, HowUniversityYatraHelps, CostOfStudying, Testimonials, GlobalEducationCTA) updated to match Ireland visual patterns. Colors consistent across all components: #1765F5 primary buttons and accents, #0C337B for headings and navy elements, #18B8B5 for teal highlights. Build produces all expected static routes without errors.

## Hero migration: video to image-based design

Both StudyInRussiaHero and StudyInAustraliaHero replaced video backgrounds with static Next.js Image components. The new structure matches StudyInIrelandHero exactly: absolute-positioned image with fill layout, gradient overlay (black/40 to transparent), centered heading with country-specific text ("Explore Medical & Technical Education in Russia" / "Build Your Future in the Land Down Under"), and two CTA buttons at bottom (consultation + WhatsApp).

Layout uses flexbox column with `min-h-[620px]`, heading positioned at top with responsive padding (`pt-[105px]` on mobile through `pt-[110px]` on desktop to clear navbar), CTAs pushed to bottom with `mt-auto`. WhatsApp links updated with country-specific context: "study options in Russia" and "study options in Australia".

## University carousels: 3D arc with country-specific data

Both UniversityCarousel components replaced Swiper.js with Canada's custom 3D arc implementation. The 3D transform logic (`getWrappedDelta`, `getScale`, `getRotY`) copied verbatim from StudyInCanada/UniversityCarousel.jsx. Russia carousel shows 12 universities (Lomonosov Moscow State, Saint Petersburg State, Kazan Federal, Novosibirsk State, Tomsk State, Bauman Moscow State Technical, Moscow Institute of Physics and Technology, National Research Nuclear University MEPhI, RUDN University, Ural Federal, ITMO, Sechenov). Australia carousel shows 8 universities (Charles Sturt, La Trobe, Griffith, University of Newcastle, Edith Cowan, Swinburne, University of Wollongong, Queensland University of Technology).

Each carousel card shows university image (webp format at `/images/universities/[university-name].webp`), university name, and city/location with MapPin icon. Cards apply 3D perspective transforms based on position relative to center: scale increases with distance, rotateY creates arc effect, translateX spaces cards horizontally. Touch and mouse drag implemented with drag state, velocity tracking, and momentum scrolling. Autoplay with 4.5s delay, pauses during drag and for 2.5s after manual interaction.

Navigation arrows positioned at bottom sides, gradient background decorations (teal and navy blurs) match Ireland pattern.

## OnlineDegreeSection: tab-based guide navigation

Both Russia and Australia OnlineDegreeSection components replaced basic layouts with Ireland's interactive tab structure. Five guides per country: study-in-[country], cost-of-studying, living-and-culture, scholarships, post-study-work-visa. Tab navigation at top shows all five guides with icons, titles, and active state highlighting. Active tab displays full guide preview card with description, key points (3-4 metrics with icons and labels), optional note, and "Read Full Guide" link.

Russia guide content covers MBBS/medical focus, engineering programs, Russian-language requirements, RUB pricing (undergraduate 120k-350k/year, postgraduate 150k-400k/year, living 15k-30k/month), September/February intakes. Australia guide content covers practical education, international rankings, AUD pricing (undergraduate 20k-45k/year, postgraduate 22k-50k/year, living 1.8k-2.5k/month), February/July intakes, post-study work via Temporary Graduate visa (subclass 485).

Tab interaction uses useState for active guide, smooth transitions with Framer Motion AnimatePresence, responsive layout (vertical stack on mobile, horizontal tabs on desktop).

## Guide pages: dynamic routes with markdown content

Both /study-in-russia/[guide] and /study-in-australia/[guide] follow Ireland's dynamic route pattern. Each country defines RUSSIA_GUIDES and AUSTRALIA_GUIDES objects with 5 guides containing: id, vol, slug, title, shortTitle, badge, tagline, heroImage, pillColors array, and markdown string.

Hero section uses gradient background (from #0C337B via #1765F5 to #0C337B), centered white text, badge pill with BookOpen icon, main heading, tagline, and pill badges with custom colors. Article section renders markdown as HTML with prose styles: headings use navy (#0C337B), body text slate (#475569), links blue (#1765F5), strong tags bold navy.

Russia guide content: study pathways (bachelor's/master's/intakes), costs (RUB pricing), living (accommodation 3k-10k/month, cultural notes about Russian winters and language), scholarships (government scholarship with stipend), work permits (employer sponsorship required). Australia guide content: education system (3-4 year bachelor's, 1-2 year master's), costs (AUD pricing), living (on-campus 600-1.2k/month, cultural notes about English-speaking environment), scholarships (merit-based), work visa (Temporary Graduate scheme details).

All 5 routes per country generated as static pages during build (confirmed in build output).
